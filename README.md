# pi-skill-improve-codebase-architecture

[![Pi Package](https://img.shields.io/badge/pi--package-skill-blue)](https://github.com/IgorGuariroba/pi-skill-improve-codebase-architecture)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**improve-codebase-architecture** skill for the **[Pi coding agent](https://pi.dev)**, adapted from Matt Pocock's Engineering Skills.

> Scan a codebase for deepening opportunities, present them as a visual HTML report, then grill through whichever one you pick.

---

## Installation

Install directly into Pi using `pi install`:

```bash
pi install git:github.com/IgorGuariroba/pi-skill-improve-codebase-architecture
```

Or clone into your local/global skills directory:

```bash
# Global Pi skills directory:
git clone https://github.com/IgorGuariroba/pi-skill-improve-codebase-architecture.git ~/.pi/agent/skills/improve-codebase-architecture

# Or Agent Skills standard path:
git clone https://github.com/IgorGuariroba/pi-skill-improve-codebase-architecture.git ~/.agents/skills/improve-codebase-architecture
```

---

## Usage

Trigger it explicitly in your session:

```text
/skill:improve-codebase-architecture
```

Or let Pi automatically route to it based on conversation context and need.
